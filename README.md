# Online Pharmacy Store Backend

A robust backend application for an Online Pharmacy Store built with Node.js, Express.js, and PostgreSQL.

## Features
- Server-side routing for pharmacy products and categories
- Stock inventory and cart management logic
- Database operations using PostgreSQL

## Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **Language:** JavaScript (ES6+)
- **Version Control:** Git & GitHub
